# ClipBoardX

Менеджер истории буфера обмена для Windows 10/11. Нативное приложение на C# / WinForms
(.NET 10), без внешних зависимостей.

## Возможности

- **Фоновое слежение за буфером** через `AddClipboardFormatListener` (`WM_CLIPBOARDUPDATE`),
  без опроса по таймеру. Записываются текст, изображения, списки файлов и (опционально) HTML.
- **История** с дедупликацией по SHA-256: повторное копирование того же содержимого
  переносит запись наверх, а не создаёт дубль.
- **Поиск и фильтры**: полнотекстовый поиск (`Ctrl+F`) + фильтр по типу записи
  (текст / HTML / изображения / файлы / закреплённые).
- **Закрепление (pin)** избранных записей — они не удаляются при очистке и при обрезке по лимиту.
- **Горячая клавиша** для вызова окна истории. По умолчанию `Ctrl+Shift+V`
  (`Win+V` и `Win+Shift+V` в Windows заняты встроенным меню истории буфера,
  поэтому занять их нельзя). Клавишу можно переназначить в настройках,
  там же есть автоматический подбор запасного сочетания.
- **Вставка в активное приложение**: `Ctrl+Enter` возвращает выбранную запись в буфер,
  отдаёт фокус окну, которое было активно до открытия истории, и отправляет `Ctrl+V`.
- **Трей**: открытие истории, закреплённые, автозапуск, очистка, выход.
- **Один экземпляр**: повторный запуск показывает окно уже работающего экземпляра.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl+Shift+V` | Показать/скрыть историю (настраивается) |
| `Ctrl+F` / `F3` | Фокус в строке поиска |
| `Enter` | Вернуть запись в буфер и скрыть окно |
| `Ctrl+Enter` | Вставить запись в активное приложение |
| `Del` | Удалить выбранную запись |
| `Esc` | Скрыть окно |
| Правая кнопка мыши | Контекстное меню записи |

## Сборка и запуск

```powershell
dotnet build ClipBoardX\ClipBoardX.csproj -c Release
.\ClipBoardX\bin\Release\net10.0-windows\ClipBoardX.exe
```

Автозапуск добавляет в реестр ключ
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` с параметром `--autostart`,
поэтому при старте из трея окно не показывается.

## Хранение данных

Всё лежит в `%APPDATA%\ClipBoardX`:

| Файл | Назначение |
|---|---|
| `history.json` | История записей |
| `settings.json` | Настройки |
| `images\*.png` | Сохранённые изображения (имя файла — хэш пикселей) |

Картинки с одинаковым содержимым сохраняются один раз: имя файла вычисляется из
SHA-256 пиксельных данных. Файлы изображений, на которые больше нет ссылок,
удаляются при запуске и при выходе.

## Известные ограничения

- `Win+V` и `Win+Shift+V` недоступны: Windows резервирует их под встроенную историю буфера.
- Clipboard читается в STA-потоке UI; если буфер занят другим приложением, выполняется
  до 8 повторов с паузой.
- Отслеживается только один глобальный буфер обмена (несколько виртуальных машин/рабочих
  столов Windows не разделяются).
